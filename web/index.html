Laboratório de Chaos & Resiliência

Validação do comportamento autônomo sob falhas graves de pods, nós e containers.

Kubernetes Workload Pod Failure

CrashLoopBackOff no Pod

Injeta um evento onde o container principal falha repetidamente com Exit Code 1. Testa a captura de logs anteriores (--previous), deduplicação no cooldown e abertura do chamado Jira.

Docker Container Memory Kill

OOMKilled no Container (Exit 137)

Simula o encerramento violento de um container por excesso de consumo de memória pelo Linux OOM-Killer. Valida a captura de métricas e abertura de chamado prioritário.

ESPECIFICAÇÃO DE ARQUITETURA UNIFICADA

Guardian Platform Architecture

O Guardian adota um modelo descentralizado baseado no conceito de Target Cirúrgico. Cada alvo definido pelo operador aloca dinamicamente goroutines em Go que conectam nos provedores pertinentes sem interferir no restante da infraestrutura.

Componente Kubernetes Engine Docker Engine
Descoberta Leitura de ~/.kube/config com highlight de contexto ativo Conexão via Unix Socket ou TCP remoto
Granularidade Namespace (ex: producao, billing) Stack Compose / Containers
Mecanismo client-go Informers & Pod Watcher Docker Engine Events Stream (die, oom)
Diagnóstico Logs do Pod anterior (--previous) Logs do Container (--tail=50)
