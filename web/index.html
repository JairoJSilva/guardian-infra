Guardian: Supervisor Híbrido de Targets

Uma única plataforma para responder a incidentes e abrir chamados no Jira automaticamente. O operador pode monitorar cirurgicamente Namespaces em múltiplos clusters Kubernetes e Stacks do Docker Compose em múltiplos servidores Docker lado a lado.

Dimensão Kubernetes Docker Puro
Ambiente / Host Cluster Context (~/.kube/config) Docker Host (/var/run/docker.sock ou SSH)
Escopo do Target Namespace (ex: billing, checkout) Compose Project / Stack
Motor de Eventos client-go Informers por Namespace Docker Events API Stream (die, oom)
Coleta de Logs kubectl logs --tail=50 --previous docker logs --tail=50
Ação no Jira Chamado com logs do Pod anexados Chamado com logs do Container anexados
