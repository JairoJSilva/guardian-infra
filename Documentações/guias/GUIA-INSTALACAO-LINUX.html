1. Experiência de Janela Nativa

Ao abrir o Guardian pelo menu, o launcher executa o modo --app. O dashboard abre em sua própria janela independente, sem barras de endereços ou abas, integrando-se perfeitamente ao dock e ao Alt-Tab do sistema.

2. Zero Overhead & Memória Mínima

O motor em Go roda em segundo plano consumindo apenas ~22 MB de RAM, monitorando continuamente múltiplos clusters Kubernetes e containers Docker de forma assíncrona.

3. Especificação XDG Base Directory

Nenhum arquivo solto no seu $HOME. Credenciais ficam em ~/.config/guardian/, estado e targets em ~/.local/share/guardian/ e logs em ~/.local/state/guardian/.

4. Automação com systemd

O serviço de usuário reinicia automaticamente em caso de falhas e pode ser gerenciado com comandos padrão systemctl --user ou pelo guardian-ctl.

Métodos Oficiais de Instalação

Escolha a opção ideal para sua estação de trabalho ou servidor

Instalação Segura e Isolada: Não requer permissões de administrador (sudo). Todos os arquivos são instalados estritamente na árvore do seu usuário (~/.local e ~/.config), preservando a integridade do sistema operacional.

1 Clone o Repositório e Execute o Instalador 

# Acesse o diretório do projeto
cd ~/Documentos/Jairo/automação-jira/guardian-infra

# Execute o instalador automatizado
make install

# Ou execute diretamente o script de instalação
./scripts/install-desktop.sh

2 O que o Instalador Configura Automaticamente

~/.local/bin/

Instala os executáveis guardian, guardian-app e guardian-ctl.

~/.local/share/applications/

Registra o guardian.desktop no menu de apps do Zorin/Ubuntu.

~/.local/share/icons/hicolor/

Instala o ícone vetorial SVG em alta resolução guardian.svg.

~/.config/systemd/user/

Registra e habilita o serviço de background guardian.service.

Verificação de PATH no terminal

Certifique-se de que o diretório ~/.local/bin esteja presente no seu $PATH para executar os comandos de qualquer lugar. Se necessário, adicione ao seu ~/.bashrc:

export PATH="$HOME/.local/bin:$PATH"
Distribuição Padronizada para Frotas: Ideal para instalar o Guardian globalmente na máquina ou distribuir para outros membros do time de Engenharia e SRE através de um arquivo .deb oficial.

1 Compilar e Gerar o Pacote .deb 

# Constrói o pacote .deb na pasta dist/
make deb

# O arquivo gerado estará em:
ls -lh dist/guardian_3.0.0_amd64.deb

2 Instalação no Sistema Operacional 

# Instalação via dpkg no Ubuntu / Debian / Zorin
sudo dpkg -i dist/guardian_3.0.0_amd64.deb

# Ou clique duas vezes no arquivo .deb pelo Gerenciador de Arquivos para instalar via Software Center
Ambiente de Desenvolvimento Rápido: Execute o Guardian diretamente pelo terminal sem necessidade de registrar atalhos de sistema. 
# Compila o binário standalone
make build

# Inicia o servidor e abre a janela de aplicativo desktop nativa
./bin/guardian -gui

# Ou rode apenas o servidor HTTP na porta desejada
./bin/guardian -port 8092

Manual de Operação CLI — guardian-ctl

Controle completo do ciclo de vida, telemetria e logs pelo terminal

CLI nativo
guardian-ctl status

Inspeciona se o motor está rodando, exibe a URL local, contadores de targets ativos e telemetria da API.

guardian-ctl open

Inicia o motor em background (se não estiver rodando) e abre imediatamente a janela nativa do aplicativo.

guardian-ctl start

Dispara o daemon do Guardian em segundo plano gerenciado pelo systemd ou como processo resiliente.

guardian-ctl stop

Interrompe graciosamente o serviço do Guardian, fechando as conexões com K8s informers e Docker socket.

guardian-ctl logs

Abre o streaming contínuo de logs da aplicação (via journalctl ou arquivo de log direto).

guardian-ctl restart

Recarrega configurações e reinicia os workers do supervisor mantendo o histórico de deduplicação.

Serviço de Segundo Plano (systemd)

Gerenciamento via systemctl nativo

O Guardian é executado como uma unidade de serviço do usuário no systemd. Isso significa que ele inicia com o seu login e não interfere nos serviços do sistema operacional. 

# Iniciar o serviço
systemctl --user start guardian

# Verificar status detalhado
systemctl --user status guardian

# Habilitar inicialização no login
systemctl --user enable guardian

# Ver logs pelo journalctl
journalctl --user -u guardian -f

Resolução de Problemas Comuns (Troubleshooting)

Dicas rápidas para diagnósticos no Linux

Porta 8092 já em uso

Se outra instância estiver rodando ou a porta estiver presa:

guardian-ctl stop
# ou altere a porta em ~/.config/guardian/guardian.env: PORT=8095
Permissão negada no socket Docker

Se você for monitorar containers Docker locais e receber erro no socket:

sudo usermod -aG docker $USER
# Reinicie a sessão ou execute: newgrp docker
Atalho não aparece no menu Zorin/GNOME

Atualize manualmente o banco de dados de atalhos e ícones da sessão:

update-desktop-database ~/.local/share/applications
gtk-update-icon-cache -f -t ~/.local/share/icons/hicolor
Como Desinstalar o Aplicativo

Para remover executáveis, atalhos do desktop e serviços mantendo seus dados:

make uninstall
# ou: ./scripts/uninstall-desktop.sh
