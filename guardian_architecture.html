Guardian: Supervisor Híbrido de Targets

Uma única plataforma para responder a incidentes e abrir chamados no Jira automaticamente. O operador define cirurgicamente quais Namespaces em Kubernetes e quais Stacks no Docker deseja monitorar, alocando recursos de watchers sob demanda.

Dimensão Kubernetes Docker Puro
Ambiente / Host Cluster Context (~/.kube/config) Docker Host (/var/run/docker.sock ou SSH/TCP)
Escopo do Target Namespace (ex: billing, checkout) Compose Stack / Labels
Motor de Eventos client-go Informers / Watcher por Namespace Docker Engine Events Stream (die, oom)
Coleta de Logs kubectl logs --tail=50 --previous docker logs --tail=50
Ação no Jira Chamado com logs do Pod anexados Chamado com logs do Container anexados
